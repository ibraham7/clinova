# لوحة الإدارة (/admin)

رابط اللوحة: `https://clinova.novanoai.online/admin`

من هنا يستطيع الإداري:

- **تعديل نصوص الموقع:** يرى نسخة حيّة من الموقع، يضغط على أي نص، ويعدّله بالعربية والإنجليزية والتركية والفرنسية.
- **فيديوهات العملاء:** يضيف فيديو برابط YouTube أو برفع ملف، ويعدّله ويرتّبه ويحذفه. قسم «تجارب حقيقية» يظهر في الموقع تلقائيًا عند إضافة أول فيديو.
- **شعارات العملاء:** يرفع شعار كل عميل جديد. الشعارات تحل محل المربعات الفارغة في قسم «شركاؤنا».
- **التقارير وسيرينا:** إحصاءات الزوار، والاستبيان، ومن ترك بياناته، مع المساعدة الذكية سيرينا. راجع [reports-and-serena.md](reports-and-serena.md).

## كيف يعمل الحفظ؟

1. كل محتوى اللوحة محفوظ في ملف واحد: `src/content/site-content.json`. الشعارات المرفوعة تُحفظ في `public/uploads/logos/`.
2. عند الضغط على «حفظ ونشر»، تحفظ اللوحة التعديل مباشرة في GitHub، فيبني Netlify الموقع من جديد تلقائيًا. **يظهر التعديل على الموقع خلال دقيقة أو دقيقتين.**
3. كل حفظ له سجل في GitHub. لاسترجاع نسخة قديمة، افتح سجل الملف `src/content/site-content.json` في GitHub (History).
4. **إذا كنت تعمل على المشروع من VS Code**، نفّذ `git pull origin main` قبل أي تعديل، لأن اللوحة تضيف تعديلات جديدة على GitHub.

المقالات (المدونة) لا تُعدَّل من اللوحة. هي ملفات في `src/blog/content/`.

## الإعداد لأول مرة (مرة واحدة على Netlify)

افتح Netlify ← مشروع clinova-medical ← **Site configuration ← Environment variables ← Add a variable**، وأضف:

### 1. كلمة سر اللوحة: `ADMIN_PASSWORD` (إلزامي)

- كلمة سر قوية لا تقل عن 10 أحرف، ويُفضّل أكثر من 16 حرفًا. هذه كلمة السر التي تعطيها للإداري.
- لتغييرها لاحقًا، عدّل القيمة ثم أعد النشر. تغييرها يُخرج كل من سجّل دخوله.

### 2. صلاحية الحفظ على GitHub: `GITHUB_TOKEN` (إلزامي)

1. افتح GitHub ← صورتك ← **Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token**.
2. املأ الحقول:
   - **Token name:** `clinova-admin`
   - **Expiration:** سنة. ضع تذكيرًا لتجديده، لأن الحفظ يتوقف عند انتهاء الرمز.
   - **Repository access:** اختر **Only select repositories** ثم `ibraham7/clinova` فقط.
   - **Permissions ← Repository permissions ← Contents:** اختر **Read and write**.
3. اضغط **Generate token**، وانسخ الرمز الذي يبدأ بـ `github_pat_`.
4. أضفه في Netlify باسم `GITHUB_TOKEN`.

### 3. رفع ملفات الفيديو: Cloudinary (اختياري)

بدون هذه الخطوة تعمل اللوحة بروابط YouTube فقط. لتفعيل رفع ملف الفيديو مباشرة:

1. أنشئ حسابًا مجانيًا على cloudinary.com. الخطة المجانية تكفي لعدد معقول من الفيديوهات.
2. انسخ **Cloud name** من لوحة Cloudinary.
3. افتح **Settings ← Upload ← Upload presets ← Add upload preset**، واضبط:
   - **Signing mode:** اختر **Unsigned**.
   - **Folder:** `clinova-videos`.
   - من الأفضل حصر الملفات في الفيديو فقط، بحجم أقصى 100 ميغابايت.
   - احفظ الإعداد وانسخ اسمه.
4. أضف في Netlify:
   - `CLOUDINARY_CLOUD_NAME` = اسم الحساب (Cloud name)
   - `CLOUDINARY_UPLOAD_PRESET` = اسم الإعداد

### 4. أعد النشر

افتح Netlify ← **Deploys ← Trigger deploy ← Deploy site**، حتى تقرأ الدوال المتغيرات الجديدة.

## شعار الموقع

من «الشعارات» ← «شعار الموقع»: اختر صورة (PNG أو JPG أو WebP)، فتُحوَّل في المتصفح إلى PNG بعرض 1200 بكسل كحد أقصى وتُعرض معاينتها على الخلفيتين الداكنة والفاتحة، ثم «حفظ ونشر الشعار» يستبدل `public/logo/logo.png` (الرأس والتذييل والواجهة والمدونة ولوحة الإدارة ونتائج البحث). أول استبدال يحفظ الشعار الأصلي في `public/logo/logo-original.png`، وزر «استرجاع الشعار الأصلي» يعيده.

## المدونة

من «المدونة» في لوحة الإدارة: قائمة المقالات (مع اللغات المنشورة وصورة الغلاف) وأزرار التعديل والحذف، و«مقالة جديدة».

- **سيرينا:** اكتب الموضوع (وملاحظات اختيارية) ثم «اكتبي المسودة بالعربية»، وبعد مراجعتها «ترجمي للإنجليزية والتركية والفرنسية». كل شيء يبقى مسودة قابلة للتعديل حتى «حفظ ونشر».
- **الحقول:** الرابط (بالإنجليزية، لا يتغير بعد النشر)، تاريخ النشر، صورة الغلاف (تُصغَّر إلى WebP بعرض 1600 بكسل)، ولكل لغة: العنوان والوصف والنص بصيغة المدونة («> » للخلاصة، «## » للأقسام، «- » للقوائم، `**عريض**`، `[رابط](/ar/blog/...)`، و`Q:`/`A:` للأسئلة الشائعة).
- **الحفظ:** `admin-articles` يحفظ كل اللغات والغلاف في commit واحد (نشر واحد) في `src/blog/content/<slug>/<lang>.md` و`public/uploads/blog/`. العربية مطلوبة؛ اللغة الفارغة لا تُنشر. الروابط المسموحة فقط: `/`، `#`، `https://`، `mailto:`، `tel:`.
- **الكتابة بالذكاء الاصطناعي:** `admin-article-ai` (Gemini، نفس مفتاح سيرينا). الاختبار: `npm run check:blog-admin`.

## الأمان

- الدخول بكلمة سر واحدة. الجلسة تدوم 12 ساعة في ملف تعريف ارتباط محمي (HttpOnly وSecure وSameSite=Strict).
- محاولات كلمة السر الخاطئة تتأخر ثانية لكل محاولة، لإبطاء التخمين.
- الخادم يتحقق من كل حفظ:
  - لا يقبل إلا نصوصًا موجودة أصلًا في الموقع.
  - لا يقبل روابط فيديو إلا من YouTube أو Cloudinary.
  - لا يقبل شعارات إلا بصيغة PNG أو JPG أو WebP بحجم حتى 1 ميغابايت. صيغة SVG مرفوضة لأنها قد تحمل أكواد.
- إذا حفظ شخصان في الوقت نفسه، يُرفض الحفظ الثاني ويُطلب تحديث الصفحة، حتى لا يضيع تعديل أحد.
- صفحة `/admin` مستبعدة من محركات البحث (`noindex` و`robots.txt`).
- الاختبار الآلي للدوال: `npm run check:admin`.
